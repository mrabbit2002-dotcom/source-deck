# D20 Dice for OBS

Separate OBS Studio plugin that adds a **D20 Dice** dock.

- **Roll / Reroll**: creates (or reuses) a Browser Source named `D20 Dice` in the current scene and plays a transparent animated D20 roll.
- **Hide / Show**: hides or shows the D20 source in the current scene.
- The final result is 1–20 and remains visible until rerolled or hidden.
- The plugin is separate from Source Deck and builds its own DLL/installer.

The visual is rendered by OBS Browser Source using a generated local HTML animation. Modern OBS installations normally include Browser Source.
